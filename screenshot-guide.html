📸 Chrome Web Store Screenshot Guide

📋 Requirements

  • Size: 1280x800 or 640x400 pixels
  • Format: PNG or JPG
  • Quantity: Minimum 1, recommended 3-5

Screenshot 1: Job Analysis in Action

  1. Go to LinkedIn Jobs or Indeed
  2. Open any job posting
  3. Click the ApplySafe extension icon in Chrome toolbar
  4. Wait for analysis to complete
  5. Press Cmd + Shift + 4 on Mac (or Windows + Shift + S on Windows)
  6. Select the popup window showing the analysis
  7. Save as screenshot1-analysis.png

Screenshot 2: Risk Score & Red Flags

  1. While the popup is open with results
  2. Make sure the risk score and red flag sections are visible
  3. Press Cmd + Shift + 4
  4. Drag to select the risk assessment area
  5. Save as screenshot2-risk-details.png

Screenshot 3: H1B Verification

  1. Analyze a job from Amazon, Google, Meta, or TikTok (they have H1B data)
  2. Scroll down in the popup to show H1B verification section
  3. Capture showing "Has sponsored X H1B visas"
  4. Save as screenshot3-h1b-verification.png

Screenshot 4: Recent Scans History (Optional)

  1. Click "Recent Scans" in the popup
  2. Show list of previously analyzed jobs
  3. Capture the history view
  4. Save as screenshot4-history.png
💡 Pro Tips:
  • Use good lighting/contrast for readability
  • Show the extension working on recognizable job sites (LinkedIn, Indeed)
  • Capture different risk levels (low, medium, high scores)
  • Make sure text is clear and not blurry

Resize Screenshots (if needed)

  1. Open screenshot in Preview app
  2. Tools → Adjust Size
  3. Change to 1280 x 800 or 640 x 400
  4. Make sure "Scale proportionally" is checked
  5. Click OK and save
🎯 Quick Test Jobs for Screenshots:
  • LinkedIn: Software Engineer
  • Indeed: Data Analyst
  • Google Careers

After taking screenshots, upload them in the Chrome Web Store Developer Console under "Store listing" → "Graphic assets"
