## 🚀 Quick Start (5 Steps)

### 1️⃣ Create Chrome Developer Account
Go to: https://chrome.google.com/webstore/devconsole/

- Sign in with your Google account
- Pay $5 developer registration fee
- Verify your email address

### 2️⃣ Upload Extension
1. Click "Create new item"
2. Select `applysafe-extension.zip` file
3. Click "Upload"
4. Wait for validation (1-5 minutes)

### 3️⃣ Fill Store Listing
Copy information from `STORE_LISTING.md`:
- **Title**: ApplySafe - AI Job Scam Detector
- **Short description**: (see file)
- **Full description**: (see file)
- **Category**: Productivity
- **Language**: English

### 4️⃣ Upload Screenshots
Create 3-5 screenshots showing:
- 📱 Main popup scanning a job
- 📊 Dashboard Overview tab
- 📜 Scan History with results
- 🤖 AI Tools (Pro features)

**Size**: 1280x800 pixels each

### 5️⃣ Submit for Review

3. Wait 1-3 business days for approval
4. You're live!

## 🚨 Common Issues & Solutions

### Issue: "Extension not loading"
**Solution**: 
- Check manifest.json for errors
- Ensure all paths are relative
- Check for syntax errors in JavaScript

### Issue: "Permissions too broad"
**Solution**:
- Only request permissions actually used
- Our permissions are minimal and justified

### Issue: "Description unclear"
**Solution**:
- Use clear, non-technical language
- Explain benefits, not technical details
- Include specific use cases

### Issue: "Violates policies"
**Solution**:
- Never collect user data without consent
- Don't track beyond usage metrics
- Remove any external injected scripts
- Be honest about what extension does
